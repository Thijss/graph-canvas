01 / Define

Edges

One edge per row: from  to  label.

  • The label is optional.
  • A line with just one name adds a floating node.
  • Multiple labels can be combined, separated by commas.
  • Repeated connections are shown as parallel lines.

02 / Group

Stations

One station per row: TYPE  node,node  name.

  • Start with SUB, CS, or SS.
  • Follow with comma-separated node labels, then an optional station name.
  • A node belongs to at most one station.
