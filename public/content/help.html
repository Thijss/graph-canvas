Define the graph

An edge connects two nodes in the graph. Edges are defined by specifying the starting node, the ending node, and an optional label.

Color and style are optional. They default to yellow and solid. Additional labels can be combined, separated by commas. For parallel edges, just repeat the definition.

Boundaries

Nodes can be boundaryed. This will color-code and add a hull around the boundaryed nodes.

Syntax:

BOUNDARY  node,node,...  name

BOUNDARY can be any word containing letters, numbers, hyphens, or underscores.

Each line defines a separate boundary; boundaries with the same type share a color.

Example:

COLOR-A  1,2  Example boundary

Use the Show Boundaries toggle to hide or show borders around boundaries.

Mark groups

Groups color their member nodes.

Syntax:

LABEL  node1,node2

Use the Show Groups toggle to hide or show group coloring.

Templates

Click Templates in the top menu to browse the built-in graph examples.

Selecting a template replaces the current Edges and Boundaries editor contents with the template data.

Move around

Drag nodes to reposition them, drag empty canvas space to pan, and use the zoom buttons to zoom.

Change the layout

Choose Physics, DAG, or Custom and adjust the available controls.

Save your work

Use Import to open a TXT graph file and Export to save TXT, PNG, or SVG.

Toggle the theme

Click the PGM logo to switch between light and dark mode.
