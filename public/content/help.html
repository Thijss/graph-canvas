Define the graph

An edge connects two nodes in the graph. Edges are defined by specifying the starting node, the ending node, and an optional label.

Example:

1  2  link

Multiple labels can be combined, separated by commas. For parallel edges, just repeat the definition.

There are special labels that modify the behavior or appearance of the edge:

Group stations

Nodes can be grouped. This will color-code and add a hull around the grouped nodes.

Syntax:

GROUP  node,node,...  name

GROUP can be any word containing letters, numbers, hyphens, or underscores.

Each line defines a separate station; stations with the same type share a color.

Example:

SUB  1,2  Substation

Use the Show Stations toggle to hide or show borders around stations.

Mark routes

Routes color their member nodes.

Syntax:

LABEL  node1,node2

Use the Show Routes toggle to hide or show route coloring.

Templates

Click Templates in the top menu to browse the built-in graph examples.

Selecting a template replaces the current Edges and Stations editor contents with the template data.

Move around

Drag nodes to reposition them, drag empty canvas space to pan, and use the zoom buttons or pinch gestures to zoom.

Change the layout

Choose Physics, DAG, or Custom and adjust the available controls.

Save your work

Use Import to open a TXT graph file and Export to save TXT, PNG, or SVG.

Toggle the theme

Click the PGM logo to switch between light and dark mode.
