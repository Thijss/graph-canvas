Define edges

An edge connects a From node to a To node. Set its color, line style, and optional label in the row.

Text mode (advanced)

Enter one item per line. A single node name adds a standalone node. Two node names create an edge; add comma-separated options after them.

  • 1 adds a standalone node.
  • 1 2 connects 1 to 2 with the default yellow, solid line.
  • Set the edge color, for example 1 2 blue.
    • Available colors: yellow, blue, green, and red.
  • Set the line style, for example 1 2 dotted.
    • Available line styles: solid and dotted.
  • 1 2 red,dotted,important combines a color, line style, and label.

Boundaries and groups

Boundaries organize nodes inside a colored hull. Groups color their member nodes without adding a hull.
Nodes can belong to multiple boundaries or groups.

Boundary text mode (advanced)

Enter one boundary per line using a TYPE, a comma-separated list of nodes, and an optional name.
Every unique TYPE on subsequent rows will convert to a different color (up to 10).
Rows with a shared TYPE will have the same color.

  • A 1,2 draws a boundary around nodes 1 and 2.
  • B 3,4 then adds a separate boundary with a new color to nodes 3 and 4.
  • B 5,6 then adds a separate boundary with the same color to nodes 5 and 6.
  • B 5,6 My Nodessupports names with spaces.
  • Only nodes defined in the Edges editor can be added to a boundary.

Canvas modes

Physics arranges connected nodes automatically. DAG lays out directed graphs in levels. Custom lets you position nodes freely.

Use the canvas toggles to show or hide directions, boundaries, and groups.

Dark mode

Click the logo in the top-left corner to switch between light and dark mode. Your choice is saved for your next visit.
